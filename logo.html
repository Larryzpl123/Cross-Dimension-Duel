横版字标 / WORDMARK  — 1200×400

网站图标 / FAVICON  — 64×64

怎么用： 512 传 itch.io 的「Cover image」旁边那个用不上，itch 没有独立 icon 位——这张主要给 GitHub 社交预览、 B站/视频号头像、以及以后打包成 App 用。
favicon：下载后放进项目根目录，在 index.html 的 <head> 里加一行 <link rel="icon" href="favicon-64.png">，浏览器标签页就有图标了。
字标：适合当视频封面的标题层、或 GitHub README 顶部的横幅。
